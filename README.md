# Wealth Advisory OS

A working wealth advisory application developed for IDBI Innovate 2026. Its rule-based engine uses customer financial profiles to provide personalised investment guidance through Asha, a conversational avatar, with a shared advisory engine and a relationship manager console for human support.

The application supports suitability assessment, goal planning, liquidity analysis, portfolio allocation, voice interaction, and contextual handoff to relationship managers. The current implementation runs on synthetic customer data; the repository also documents the architecture for bank and AI service integrations.
