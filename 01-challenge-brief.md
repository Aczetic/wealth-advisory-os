# Wealth Advisory — Problem and Scope

## Problem

Wealth management and advisory services remain fragmented and inaccessible to many customers. Incomplete insight into investment behaviour and spending patterns limits timely, personalised financial guidance.

## Solution

Wealth Advisory OS combines a conversational avatar, a rule-based financial engine, and a relationship manager console. Customer financial profiles inform suitability assessment, goal planning, liquidity analysis, and portfolio allocation. Asha presents recommendations and transfers context to a human relationship manager when needed.

## Integration scope

The architecture is designed for embedding in a bank’s mobile application. It separates financial calculations from conversation services and includes customer memory, consent controls, and recommendation audit trails.

The current application uses synthetic customer profiles. Bank API connections and external language-model integration are documented deployment extensions.
